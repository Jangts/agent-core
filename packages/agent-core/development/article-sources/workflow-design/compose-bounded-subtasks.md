# 共享预算下的子任务组合

一份停机报告需要分别读取监控与变更记录，最后拼出带时间线的说明。两个读取都能独立完成时，可以并发。若一个查询必须使用另一个查询返回的服务 ID，就把依赖写进父流程的顺序。

## 把调用额度留在父任务

普通函数可直接组合确定性工作。需要自己的模型交互、进度和生命期时，用 `createChild` 创建有界子 Runner，按需绑定到常规 handler 或 Engine。父任务须为最终汇总预留额度，子任务使用同一上游账本。调用尝试即使失败也进入记账。子任务工具权限由应用重新绑定。

`Support.runChildren` 适合一组有限独立任务。为分支指定稳定 ID、调用限制、并发上限和截止时间。验收回调对每份结果做检查。组内失败会取消同组工作，迟到结果不可提交，已执行的外部写入须由业务端口确认。

## 按稳定顺序汇合结果

`aggregateBranchResults` 可以按声明顺序收拢分支成果并检测父状态顶层字段的写入冲突。一份失败时可以保留其他分支的成果，完整父提交需要满足汇合的成功条件。将读监控与读变更的结果写到各自字段。两个分支都改同一个结论时，由父任务明确决定取舍。多项真实写入需要原子性时，由应用使用一次事务提交。
