# Manage context length and delivery scope

A user asks for a complete comparison of two product collections. The application already has the shared IDs, but the raw records exceed the next model call's capacity. Compute the differences in code and send those results with the evidence needed to explain them. The complete conclusion can still be delivered.

## Reduce what the current call needs to read

| Situation | Action | Preserve |
| --- | --- | --- |
| Records are long and required fields are known | Project fields, aggregate, or read selected sections | Source IDs, revisions, and the scope available for rereading |
| History is long and recent turns establish meaning | Retain complete recent turns and summarize selected older material | Recent corrections, open questions, and references to originals |
| A summary may alter a value or eligibility condition | Reread the source and extract structured facts | Units, conditions, exceptions, and permissions |
| A required source denies access or remains unavailable | Deliver the verified scope and describe the gap | Authorized results and the actual blocker |

`Support.createContextProcessingNode` applies the application's policy to a context plan. Check for projection or rereading before spending a model call on a summary. Preserve instructions and policy-protected fragments. A summary retains the trust limits of its source. Use the returned prepared handle so measurement and invocation share the prepared constraints.

## Narrow delivery when a requirement is blocked

If the price source denies access, deliver the verified catalog differences and say that prices could not be checked. If a missing condition makes the conclusion unusable, ask for the condition before presenting it. Track context size, invocation allowance, and evidence gaps separately so the next decision can address the actual constraint.

Run `node node_modules/@jangts/agent-core/development/docs/examples/organization-comparison.mjs` to compare a stalled read with normal delivery. For a custom compressor, test that quantities, negation, recent corrections, and source scope remain recoverable.
