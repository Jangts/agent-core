# App 接入检查

[返回开发指南](README.md) · [API 参考](api/README.md)

以下是接入时应有的证据，供开发者按实际启用能力选择；不是每次修改都要执行的全套命令。源码可确认的先审阅，存在具体疑问时运行最小相关检查。离线替身成功不能证明真实模型效果，框架能执行不能证明业务事实正确。

| 边界 | 应证明什么 | 最小例子 |
| --- | --- | --- |
| 独立消费 | 仅凭交付包、依赖与文档可用 | 独立目录按公开 exports 导入，无应用路径别名 |
| 空资料准备 | 没有事实时保持空资料 | 既有项目无来源时，资料文件为空，清单无虚构内容 |
| 来源导入 | 忠实保留来源与版本 | supplied-source 字节一致；锚点非法、重复章节或超限拒绝 |
| 注册与引用 | 清单真驱动运行，引用有目标 | 未知节点／tool／reader／章节／check 有明确失败 |
| 协议解析 | schema 与实际输入检查一致 | 未知字段、无效值、错误输出拒绝；parse 无业务副作用 |
| 执行 | 只执行允许范围，回执真实 | 模型声称成功但未执行时不得返回成功 |
| 资料选择 | self／subtree／document 边界正确 | 子章节排除／包含、未知 ID、超限和版本变化 |
| 隔离 | 身份与状态不串用户 | 另一用户 ID 拒绝；旧请求不混入新目录 |
| 取消与预算 | I/O 与重试都有边界 | 超时、取消、断流、修正预算耗尽正确结束 |
| 输出 | 引用和动作状态由程序绑定 | 数字、来源、链接和不完整结果被检查 |
| 增长与维护 | 候选不会自动晋升发布 | 准备候选不改生效源；失败保留旧版；引用破坏拒绝 |
| 诊断 | 错误可定位且记录不改变执行 | 同一请求关联阶段、代码、耗时，无凭据和未授权正文 |

选用长期记忆时额外验证消息水位、并发版本、租约恢复、幂等、删除传播和来源优先级；不启用则不必建立这些服务。选用跨端操作时验证真实对端 handler 和回执；不用 Interaction Kit 也不影响接入 Core。

审查同类能力时应横向对照普通循环、Workflow、独立 Runner、工具目录、手写端口及所用 Kit，确认同一保证由实际入口执行，不能只验证推荐 Support 写法。取消分别检查预取消、中途取消、迟到返回及保存中取消；输入分别检查非法预算、注册后替换和跨 await 的可变引用；发布分别检查核验前后及提交前的有效期。

取消用例还应覆盖计数器、检查器、观察器等同步回调内部触发取消，以及同一节点中的多个处理阶段。Provider 替身应分别记录普通 `stream()` 方法入口和异步迭代器读取，避免只有 generator 的测试掩盖已取消后仍进入 I/O 工厂的问题。读取器忽略取消、证据在读取中到期、发现分页失败后不留下部分可读范围，以及迭代器清理异常不覆盖原始结果，均须按各自边界验证。

报告应区分正常合同下的运行缺陷、非法配置／接入误用的拒绝不足，以及内部加固或性能优化。回归通过只证明其覆盖的边界，不能替代 App 权限事实、真实存储原子性、外部副作用回执或真实模型效果验证，也不构成整体无缺陷的证明。

## 当前范本的明确范围

开发套件提供已有项目集成指南，以及章节解析与目录编译、候选准备、只读计划和共享校验入口。资料准备时有实际来源则据实整理，无来源保持空文件。生产 App 的身份系统、资料权限、上传解析、存储事务、画像合并、经验发布和索引仍需自行实现。

局部代码示例见[快速接入](getting-started.md)和[示例](examples.md)。[离线完整示例](examples/offline-agent.md)包含可复制运行的服务问答代码，使用 Support 工具目录和离线 Provider，不需要模型凭据。验证真实模型行为时，需要使用可用模型服务与 App 配置，分别检查语义结果、工具选择和完成性。
