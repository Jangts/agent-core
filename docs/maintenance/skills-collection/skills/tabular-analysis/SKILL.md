# 表格分析

## 输入与接入

输入包含可查询表格引用、问题和已知范围。App 用 `describe` 提供字段、类型和操作能力，用 `query` 执行受限的程序查询；可提供 `read` 获取必要明细、`check` 校验特定口径。分析依赖真实查询结果，不要求模型自行写或运行任意代码。

## 流程

1. 从实际表结构确定日期、数值、分类、单位及所需字段。字段标题相似不证明含义相同；只追问会改变结果的口径。
2. 确定期间、对象范围、分组、去重键和缺失值处理。未提供的值保持未知，不能自动补零、跨表关联或推定分类。
3. 构造当前端口实际支持的最小查询。筛选、计算、排序和汇总由程序完成；没有能力的操作明确说明，不用模型口算冒充执行。
4. 查询返回统计值、结果引用、实际覆盖与必要预览。预览行数和总统计范围分别说明，不把截断预览当全表输入。
5. 核对单位、分子分母、除零、缺值、日期边界和查询异常。有可靠交易或实体键才能去重；同名或同额不自动等于重复。
6. 解释与问题相关的统计，区分原始值、计算值和业务解释。完整结果与部分覆盖分别表达；可继续查询时沿真实游标接续。
7. 精确结果不支持某个结论时保留限制；不得用展示时四舍五入的数字回算出另一个“精确”结果。

## 结果与完成条件

交付程序结果、来源引用、统计口径、覆盖范围与异常。完成以本次问题所需查询是否执行及口径是否清楚为准，不自动扩展为全量数据审计。

## 边界

方法不提供特定数据库、SQL 方言、业务指标或任意脚本执行器。结果导出、原表修改和跨来源合并需有独立真实能力；本流程默认只分析。

## 验收场景

- 工具对全部数据汇总但只展示十行：使用实际统计值，同时标明预览有限。
- 金额混用不同单位：先按明确规则规范化或分开报告，不直接求和。
- 端口不支持跨表关联或月份提取：给出当前可执行分析及缺口，不发明操作。
