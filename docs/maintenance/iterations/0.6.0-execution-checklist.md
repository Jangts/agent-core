# Agent Core 0.6.0 执行清单

日期：2026-11-12。依据：[迭代计划](0.6.0-iteration-plan.md)。本文件跟踪实施与验收，不作为正式 API 合同。用户已同意迭代方向；以下实现项尚未完成，版本号仍为暂定。

完成规则：源码、相关回归及受影响消费者／文档均闭合后才勾选；仅复现缺陷、完成代码或通过类型检查，不等于该项完成。具体测试按未决疑问选最小范围，最终稳定后集中跑完整回归。

第一批退出条件：四个已知问题均有独立、稳定的回归；A01明确可实现的行为，不再承诺共享宿主的裸属性能自动识别并发请求。

## 实施记录

各批次完成后在此追加结果和证据链接，保留失败原因及未验证边界。实施与验证结果见[0.6.0 实施验收记录](0.6.0-implementation-acceptance.md)。E03已关闭：正式测试校正后，两端相关回归与附件读取79项通过；E04已完成来源、类型化示例及API生成检查，未构建完整静态站点；E06／E07为后续发布工作。

最终Runner选择：共享宿主的执行状态getter明确拒绝无execution归属的读取；覆写方法使用已有请求execution取得绑定。C03评估后保留无法从原始JSON Schema与任意parser静态证明的关联，不增加重复声明。C06核对两端已有请求绑定后没有强行引入新封装。C07保留已有编译缓存和Prepared快照，不跨请求缓存动态候选或collector；以上三项的完成表示评估与约束落实，不声称新增了类型推断或性能收益。
