# 乙计划 DeepSeek 真实服务验证

日期：2026-11-25。对象：DeepSeek 官方直连、模型别名 deepseek-flash、当前工作区 Agent Core。用户明确要求先验证 DeepSeek 支持的部分；其他厂商协议由 MockGPT 能力核对及模拟提案独立处理。本记录不是五家真实服务或全部乙计划验收。

## 配置与执行边界

凭据来源为 main/apps/server/.env 的现有 AI 配置，未在本文、测试输出或请求 URL 中记录。未修改配置、读取业务数据或调用业务写工具。测试只使用合成问题、只读 lookup 和程序构造的 64×64 红色 PNG。原配置模型为 deepseek-flash，远端未提供具体权重修订号，不能将别名当成固定模型版本。

调用链为 Support.createModelProvider → ModelRunner → transport；工具参数仍经过本地 parser。第一阶段使用注入 fetch 合并显式测试 profile，Chat／Messages thinking.disabled，Responses reasoning.effort=none。该 profile 是测试接线，不伪称首轮已验证公共 requestBody 配置。后续公共 profile 和思考续接验证独立记录。

测试源为 test/yi-deepseek-live.test.mjs，默认无 opt-in 凭据时跳过。YI_DEEPSEEK_LIVE=1 与 YI_DEEPSEEK_API_KEY 显式启用；可选 YI_DEEPSEEK_MODEL、YI_DEEPSEEK_BASE_URL。最终测试默认使用公共 requestBody；YI_DEEPSEEK_PUBLIC_PROFILE=0 仅用于复现第一阶段的历史注入方式，正常验证不需要该选项。YI_DEEPSEEK_SCENARIO 可选 chat-completions／responses／messages 做工具两轮专项、image 做图像专项、thinking 做公共 profile 思考专项；没有 scenario 时跑三协议普通文本及工具链和完整 HTTP JSON。凭据只通过环境注入，不由正式测试自动搜取本机文件。

## 官方支持核对

| 能力 | 官方合同／本轮范围 |
| --- | --- |
| Chat Completions | 官方 /chat/completions；支持 SSE、JSON 对象和工具，思考工具需完整回传 reasoning_content |
| Responses | 官方 /responses；支持 SSE、JSON／schema、工具及图片；关闭思考使用 reasoning.effort=none |
| Messages | 官方兼容 Anthropic；本工厂 baseUrl 为 https://api.deepseek.com/anthropic/v1，再追加 /messages；支持 system、流、客户端工具及签名内容 |
| Messages 原生结构化 | 官方 output_config 仅 effort，不能将原生 Anthropic JSON Schema 能力自动视作 DeepSeek 支持；本轮不作通过声明 |
| Flash 图片 | 当前 Flash 官方支持图片输入，本轮验证 Chat 图片 data URL；未遍历所有格式、尺寸、协议及 Files API |
| Gemini 协议、Batch、实时 | 未找到对应 DeepSeek 官方通用协议承诺，本轮不尝试将其他厂商能力套到此端点 |
| 独立 OCR／ASR／TTS／搜索 API | 官方有独立产品入口，不是本轮通用会话工厂的全产品验证；未执行 |

来源：[Responses](https://api-docs.deepseek.com/guides/responses_api/)、[Anthropic 兼容](https://api-docs.deepseek.com/guides/anthropic_api/)、[思考模式](https://api-docs.deepseek.com/guides/thinking_mode/)、[工具调用](https://api-docs.deepseek.com/guides/tool_calls/)、[JSON](https://api-docs.deepseek.com/guides/json_mode/)。字段、模型支持核对时点为本记录日期，不能替代后续版本验证。

## 第一阶段真实结果

共 12 次请求，HTTP 均为 200；上游报告累计输入 2362、输出 128、总计 2490 token。网络响应时间仅作执行记录，不作为性能或容量证据。

| 场景 | 请求数 | 结果与边界 |
| --- | --- | --- |
| Chat SSE 文本 | 1 | OK 文本与正常终态通过 |
| Chat 空对象工具参数 | 1 | 模型返回额外 parameters 属性，本地 parser 拒绝；没有执行工具或发终轮。这是真实语义失败，不弱化校验掩盖 |
| Responses SSE 文本＋工具两轮 | 3 | 文本、提案、只读工具授权执行、结果关联及正常终态通过 |
| Messages SSE 文本＋工具两轮 | 3 | 文本、提案、只读工具授权执行、中立续接状态通道与结果关联通过；非思考 profile，不据此宣称签名思考块已验证 |
| Chat 完整 HTTP JSON | 1 | JSON 模式及本地 schema parser 通过 |
| Chat 明确必填 q=probe 工具两轮 | 2 | 较明确的合成工具定义下两轮通过；不抹去前次模型参数不合规事实 |
| Chat Flash 图片 | 1 | 64×64 红色 PNG 的主色识别及 typed image 请求路径通过 |

新增图片用例最初将消息数组误作 invoke 简写而被本地拒绝，未发网络请求；已改为 invoke({input: messages})，不计入真实请求数。这是测试接线修正，不是远端服务失败。

## 公共 profile 与思考续接

主审第五轮统一构建后，用公共 requestBody 开启 thinking.enabled、reasoning_effort=low，maxOutputTokens=512，执行两次合成工具往返。第一轮收到一个符合 q=probe schema 的工具提案，断言受控 continuation 保存 reasoning_content；第二轮回传该私有状态及合成库存结果，服务端正常完成，未再提出工具，答案包含 7。未输出思考原文或把它写入普通结果日志。

两次请求均 HTTP 200，上游报告输入 344／423、输出 62／2，总计 831 token。执行 Node 24.9.0。此项验证公共 profile、Chat 思考工具状态保真及回放，不等于所有协议的思考／签名实现均已真实验证。

## 最终证据及未验证项

累计真实请求 14 次，全部 HTTP 200；报告输入 3129、输出 192、总计 3321 token。一次模型参数不合规导致本地 parser 正确拒绝，该失败保留；后续明确必填参数的独立工具场景通过，不按“所有请求通过”汇总。没有容量／并发压测，没有真实业务写入。

三类真实协议、完整 HTTP JSON、SSE、授权工具两轮、Flash 图片和 Chat 思考工具回放具备本轮证据。未验证原生严格 schema、多工具同轮并行、全部图片格式、托管搜索、后台／批量、实时音视频或独立产品 API；不能凭官方目录或离线 fixture 宣称通过。DeepSeek Messages 不支持的 output_config.format 不能通过兼容 Anthropic 协议的通用能力声明绕过。

正式测试在无 opt-in 凭据时 6 项全部跳过，默认不会访问网络；主审可将其纳入普通回归但应保留跳过边界。临时凭据装配脚本与本轮日志在将必要元数据写入本记录后清理。
