# 甲计划七方实现与测试复审

日期：2026-11-25。依据：[甲计划](1.0.0-plan-jia.md)。本次复核实际实现、验收断言和交付物，发现问题后直接修复；首轮数字保留为历史证据，以本文作为修复后本地验收结果。范围仍限甲计划，不代表整个 1.0.0 完成或发布。

## 七方覆盖与处理

| Agent | 审计范围 | 发现及实际处理 |
| --- | --- | --- |
| audit_coverage | A—E 与 P0—P4 逐项覆盖、验收真实性 | 补齐 A3 普通 handler 同任务对照、双语说明及回归；指出 R2 原示例未真正进入 reconcile，由等待方补齐 |
| audit_durable | 持久状态、授权、恢复与未知副作用 | 取消终态先执行当前 read 授权；拒绝当前步骤未登记尝试的 running 检查点；reconcile 策略缺少 handler 时在注册阶段拒绝，避免首次副作用后才发现无法恢复 |
| audit_wait | 等待、幂等、取消与跨进程恢复 | 构造配置、身份和端口 getter 只读取一次并保留 receiver；补取消期间锁保持回归；R2 四进程实际验证保存后响应丢失及新进程对账 |
| audit_aggregation | 并发汇合、冲突、输入隔离 | 先捕获声明顺序与输入快照；结果 getter 只读取一次，防止 getter 重入修改分支声明、改变接纳顺序 |
| audit_observers | 父子观察、快照、事件隔离 | 事件 scope 的 observe 配置只读取一次，补 getter 回归，保持同源订阅去重与构造时快照 |
| audit_budget | 多 Runner、调用额度与同／异 key | 修复真实测试诊断按所选 pair 比较；新增同 key／异 key 的并发 429 与成功响应隔离、失败计账及额度耗尽后无网络请求断言；明确计数含已准入未完成及失败请求 |
| audit_external | 外部运行时边界与可重复证据 | 把临时原型改为正式可选契约测试；固定真实 LangChain 依赖，覆盖正常、模型失败、工具失败、取消晚到、独立额度五场景，未引入 Core 必需依赖 |

每批保持单一文件负责人；总整合方核对实现、编译及回归。Durable 注册时拒绝缺失 reconcile 的规则已与原审计方对齐。七方无未解决分歧，没有触发“其余六人投票、3:3 交用户”的规则。

## 补齐的验收证据

A3 新增公开 `harness-handler-comparison` 示例及中英文指南：普通 handler 与工作流使用同任务、同 Provider 调用序列和共享四次额度；比对成功、超额、授权拒绝且无保存。说明选择条件，不宣称任何结构普遍更简单。

R2 的 `harness-durable` 现为四个独立进程：产生已持久化成果并等待；保存成功后合成响应丢失，保留 running／unknown；新进程实际 reconcile 并持久确认；执行期限后只读查询。断言成果与保存各一次、confirmationCount=1、尝试数不增加。正式回归实际调用示例。故障是保存成功后的合成错误，不能据此宣称验证断电、SIGKILL 或磁盘崩溃。

外部契约测试使用 langchain 1.6.8、@langchain/core 1.5.1、@langchain/langgraph 1.7.5、zod 4.6.7，隔离安装并以 `EXTERNAL_AGENT_DEPENDENCIES` 指定路径。默认不安装、不联网，五项显式跳过；启用后调用真实 createAgent、tool 和 middleware。外部循环额度归独立资源域，Core 账本不虚报内部模型计账。
