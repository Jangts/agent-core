## 迁移规则

- 规范名只有一组实现；0.9 公开符号如保留兼容，明确标记 deprecated，重导出同一个对象/函数或转发到同一个方法，不复制执行逻辑。稳定分发的兼容入口按政策维护整个 1.x。
- 当前 consumer、示例、生成来源与正式文档使用规范名；旧名仅在兼容声明、升级说明及历史记录中使用。
- 配置名桥接须保留缺省和精确类型，新旧键冲突显式拒绝；只选择值/映射参数，不额外调用模型、工具或创建新任务。
- 诊断记录、snapshot、WaitRecord、Durable、Family、continuation 的现有格式、寻址、版本、操作和提交身份优先保持。源码名变化不要求升保存版本，不引入无需求的 decoder 或数据回写。
- 本案不是丙增补实施授权；未被实际采用的新参与者体系不加入公共稳定面。

## 验证范围与理由

跨域重命名涉及继承、结果泛型、ESM/CJS 入口身份、自定义 adapter 及旧配置解析，单靠文本替换无法证明正确。各域先进行源码推理；统一接入后执行必要的公共包构建、受影响的类型与定向回归，疑问消除后不无谓重复。最终 tarball 的仓外安装用于检查实际交付及隐式 workspace 依赖，不能用源码测试替代。

不自动启动 UI、应用服务或压测，不进行真实付费模型调用。甲乙丙历史真服务/故障证据按相应工件与保证复用；更名触达的合同最小重验，未验证厂商、设备、磁盘崩溃和生产容量仍未验证。

## D0 定稿及兼容例外

公开名和 transitive 声明形状由 [公共合同快照](1.0.0-public-contracts.json)记录，`scripts/check-concepts.mjs` 按真实 source exports 检查术语并内存生成 d.ts 形状指纹，避免只核对名称。维护 JSON 不被运行时导入。保存格式、读写范围和宿主前提见[格式合同](1.0.0-ding-formats.json)。

两项明确的 0.9 输入类型迁移：

1. 旧 PreparedModelInteraction 表示单选准备，迁为 PreparedModelSelection；最终准备合同采用 PreparedModelInteraction，旧 PreparedModelTransport 保留指向它的兼容别名。不能同时保留旧同名的另一种语义，也不为旧名选取不准确的长期名。
2. 旧 NodeReportingContext 本身不增必填，但 ToolExecutionContext、WorkflowContext 和 Core 回调的增强上下文间接要求 createStepRecorder；手工构造的旧对象/替身显式绑定原 factory，不能断言为新类型。中英升级说明已列出适配及 receiver/signal/report 前提，甲原设计者定向确认此迁移可接受。

甲确认 ReportedStepRecorder/Record、WorkflowRunTrace/NodeVisit、BranchVersioning/Record/Store、AgentSnapshot 整族及旧格式保持；乙确认 ModelInteraction、两个 Prepared、单次 ModelToolResponse、ModelProvider 能力组合及模型生命周期限定；丙确认 ResultReview/Decision/Choice 分工、版本聚合记录及 DomainTool/LifecycleTool 分离。BranchVersions 仅是同一服务工厂的便捷 namespace，不是另一组 Agent 或实例。

## 回归修正与定向影响检查

首轮 SDK 库级回归 1216 项中 1187 通过、14 失败、15 跳过。失败均逐项定位：Engine 漏转发 canonical interaction、旧子任务列表未快照、策略配置缺旧结构读取视图、泛型推导遗漏旧字段分支、selector 原校验优先级、旧错误文本匹配、同实现支持方法被误当双键冲突，以及新轨迹测试使用空事件。修复实现/真实 fixture，未放宽旧断言、预算或投影验证。后续一轮只剩策略返回配置的旧 transports 读取视图，补同一数组的只读别名后，库级回归零失败。

独立 ding_impact_check 按 eight-role-review 的影响面/回查规则定向审阅，未重启八方全文评审。其唯一实质发现是 Microcola 分隔符校验 transport 标签被误改，已恢复；Banker 故障规则 id 也按保守身份保持建议恢复 transport。原方回查确认，未声称已发生外部告警故障。模型投影的 availableGoals/availableGoalIds/goalIds、中英概念说明及旧保存字面量已明确保留。检查只能按真实更名触达归因，不能把混有其他工作区改动的全部暂存差异认作丁。
