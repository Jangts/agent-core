## 影响面与取舍

| 受影响者／触发 | 负面影响 | 缓解与发现信号 | 剩余边界 |
| --- | --- | --- | --- |
| 活跃账号分钟增量与日复核 | 调用次数、输入量、费用可能增加 | 每用户每轮最多8次，增量6批、复核1批，输入/输出/时间有界；无待处理事项不调用；诊断记录active/deferred数量 | 不是日/月费用封顶，实际费用未评测 |
| 长期积累超过64条活跃 | 较旧但仍有效偏好退出自动上下文 | 保留needs-review候选，新明确表达可激活，容量诊断及回归 | 不承诺全部累计偏好始终自动生效 |
| 总版本超过128 | 历史版本与墓碑不能无限保存 | 退休时间下界阻止旧来源复活 | 保守忽略下界及之前尚未记录内容；不是无损历史档案 |
| 旧摘要迁移 | 短期仍可能带有过期或错误推断 | 独立未核实标记、当前及有来源条目优先、固定期限、明确纠正删除片段 | 未迁移为有证据条目部分到期退出上下文 |
| 拟稿、引用、客户材料或注入 | 模型可能误归属于用户 | 注册种类、来源身份及引句校验，App排除政策，低信任上下文、人工资料优先 | 结构匹配不证明语义/现实；需真实模型负例验收 |
| SQLite0088升级 | 旧程序不能直接读取新迁移台账 | 保留数据、重复升级幂等测试；不改历史哈希或清库 | 程序回退不等于数据回退；本轮不部署 |
| 极大同时间戳组 | 组无法装入批次时退避而不推进水位 | 记录失败、保留原状态，诊断后人工处理 | 不静默跳过该组，不承诺任意大输入自动恢复 |
| 其他SDK消费者 | 新个人记忆合同及可选入口 | 未采用Kit无需迁移；Core未新增必填字段或业务阶段 | 本轮不构成全包发行验收 |

这些取舍已在原角色回查中披露，未发生需要九席表决的剩余方案分歧，不以票数替代证据。
