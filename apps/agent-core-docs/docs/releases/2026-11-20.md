# 2026-11-20 发布记录

## SDK 0.8.1

武汉 Pages 的 Agent Core 文档站已更新至 SDK 0.8.1。中英文手册与上线前检查清单均可进入 Agent 稳健性检查和分层测试，手册包含 JS／TS 接线说明和可运行的节点测试示例。 [中文手册](https://agent-core-docs.pages.jangts.cafe/zh/manual/workflow-development.html) · [English handbook](https://agent-core-docs.pages.jangts.cafe/en/manual/workflow-development.html)

- 双语构建和整站检查通过，上传包及远端 5,460 个静态文件通过 SHA-256 校验。
- 公网 API 清单返回 0.8.1，含 47 个导出模块和 654 个公开符号。20 个公网响应的状态、类型和 SHA-256 与本地构建一致，缺失页面返回 HTTP 404。 [公网 API 清单](https://agent-core-docs.pages.jangts.cafe/api-catalog.json)

构建报告了静态资源体积警告。验证范围为构建、静态内容与公网响应。

构建报告了静态资源体积警告。验证范围为构建、静态内容与公网响应。

## SDK 0.7.0

武汉 Pages 的 Agent Core 文档站已更新至 SDK 0.7.0，公开 API 清单包含 47 个导出入口和 654 个公开符号。发布入口与服务器目录见[部署说明](../deployment.md)。

- 中英文开发手册均包含 **API 使用手册 → SKILLs** 入口，页面列出 16 个通用 Skill 并提供 App 接入示例。[中文](https://agent-core-docs.pages.jangts.cafe/zh/manual/api/skills.html) · [English](https://agent-core-docs.pages.jangts.cafe/en/manual/api/skills.html)
- VitePress 构建与完整站点检查通过，上传包及服务器端 5,442 个文件的 SHA-256 校验通过。
- 公网 HTTPS 首页、中英文 API 目录、Workflow、Kit、SKILLs、API 清单、站点地图和页面引用的 JS、CSS 均与本地成品的 SHA-256 一致。中英文导航链接和 Skill 清单已核对，缺失页面返回 HTTP 404。

构建报告了静态资源体积警告。验证范围为构建、静态内容与公网响应，浏览器交互和视觉验收由用户负责。
